# 静态资源

本目录只存放由 CampusPulse AI 项目自制或获准使用的静态资源，由 Next.js 从 `/` 路径公开访问。

- 品牌图标：`campuspulse-icon.svg`
- Next.js 初始模板图形：`file.svg`、`globe.svg`、`next.svg`、`vercel.svg`、`window.svg`；若页面不再引用，可在确认无依赖后清理。
- 竞赛 PDF 插图统一存放在 `docs/assets/`，不应复制到公开静态资源目录，除非产品页面确实需要。

添加资源前检查来源、授权、可访问性文本和构建产物体积；不得提交真实用户头像、个人信息、密钥截图或未获授权的图片。
