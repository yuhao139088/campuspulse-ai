# 测试素材与验收步骤

这些素材全部为原创生成的合成数据，不包含真实学生信息。不要把测试结论作为真实校园经营结果。系统管理员可在后台选择任意空间；数据隔离测试请使用两个普通用户。

## 手动验收

1. 邮箱注册：发送验证码、填写错误验证码、正确注册；验证码过期/重复使用应失败。163 SMTP可能有垃圾邮件判定，请同时查看垃圾箱。
2. 注册两个普通账号A/B，各自导入独立数据。A复制数据集URL交给B，B应看不到A的资料。
3. 对01提问“报名与签到总数是多少，请调用聚合工具分别计算”；检查真实工具链与来源。提问“哪个活动预算效率最低”时核对实际数据和单位。
4. 导入07与08，打开数据详情，核对OCR原文、结构化字段及实际模型名称。不要只检查状态标签。
5. 创建柱状、折线和饼图，增加与删除后刷新/重新登录，确认云端状态与PNG导出。
6. 创建中文/英文报告，生成过程中重复按钮禁用；修改后保存，检查历史版本及DOCX/Markdown下载。
7. 在个人设置输入当前密码，绑定Authenticator“其他账户”，输入6位认证码开启2FA。**立即保存十个恢复码**。旧会话应失效；重新登录需新认证码或未使用恢复码。
8. 同一认证码与恢复码不得重复登录。关闭2FA需当前密码与认证码/恢复码，关闭后旧会话也失效。
9. 系统管理员进入“管理员空间→平台管理→全站配置中心”，更改公告、测试邮件/AI连接；普通空间管理员请求 `/api/platform/config` 应为403。
10. 手机注册、登录与绑定需先提供真实短信供应商。尚未配置时按钮不可用或接口明确返回503，不能显示伪造的发送成功。
