# 测试素材与验收指南

仓库中的 `data/test-materials/` 已附原创合成记录，不包含真实学生信息；生成器也可重新创建同类测试数据。素材用于验证导入、计算与界面流程，不代表实际校园运营结果。

## 生成素材

    python tools/generate-test-assets.py /path/to/test-materials
    node tools/generate-test-images.mjs /path/to/test-materials

第一个命令生成 6 个表格文件；第二个命令生成 OCR 图片、空白图像和不支持格式文件。命令行输出目录建议放在仓库外；仓库中的 `data/test-materials/` 是专门纳入评审包的稳定夹具。

## 关键期望值

基础 CSV/XLSX 为 12 行、6 列。合成数据报名人数合计 1061，签到人数合计 817；2026 年 10 月 OpenDay 报名 160、签到 60，签到率 37.5%。计算需以导入后的真实数据为依据。

OCR 示例图片包含日期 2026-10-12、报名 56、签到 43、预算 1280 CNY 和地点 Campus Hall。识别表格时应将每一条明细展开成独立数据记录；详情页应同时保留可复核的原始 OCR 证据。

重复/缺失/异常素材用于检查重复清理、空值提示及极端值候选；重复表头素材应拒绝导入。中文表头用于验证中文字段名、图表与自然语言分析。空间隔离素材应通过两个普通用户分别导入后检查，系统管理员不适用于隔离测试。

## 浏览器与质量检查

    npm run typecheck
    npm run lint
    npm test
    npm run build
    npm run test:e2e

提交前检查桌面、平板和窄屏下首页、登录、数据空间、详情、AI 分析、画布、报告、设置及管理员页面。测试环境应使用专用数据库、对象存储和密钥；不得连生产数据库执行夹具或清理命令。

## 人工验收流程

1. 使用测试账号登录，查看当前可用的认证选项和站点语言。
2. 导入基础 CSV、XLSX 与中文表格，核对行列、合计与字段字典。
3. 导入重复/缺失/异常素材，确认提示明确，不把异常候选描述为已证实错误。
4. 导入 OCR 图片，核对结构化行数、字段值和原始识别证据。
5. 选择数据集提问并查看工具轨迹、分组、过滤条件和计算结果；人工对照原始行核验。
6. 将图表建议导入对应数据集画布。切换数据源后，不应显示其他数据集的图表。
7. 生成和编辑报告，检查历史版本及导出内容；创建行动项并检查成员权限。
8. 用两个普通账号验证资源隔离与只读/编辑权限。
9. 若已配置邮件、短信、OAuth 或人机验证，逐一测试真实供应商链路；仅用模拟回包不算供应商验收。
10. 若启用 TOTP，验证一次性验证码、恢复码、重放拒绝和安全设置流程。

自动测试验证代码路径和边界条件，不等于独立模型基准、真实用户试点或安全认证。测试结论应附实际命令输出与环境，不从文档中的预期反推测试成功。
