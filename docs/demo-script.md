# CampusPulse AI 演示视频稿（详细分镜版 · 约 7 分 30 秒）

本稿用于录制 5–8 分钟中文演示视频，覆盖 v0.2.0 的完整业务链路：数据导入（含图片 OCR 表格按行展开）、AI Agent 分析、图表画布（按数据源隔离）、双语报告、协作权限与系统配置（含 GitHub 授权登录）。每一镜给出时间、画面、逐步操作、逐字旁白、字幕标注与易错点，可直接交给录制与剪辑执行。

## 一、成片规格

- 成片时长：7 分 30 秒，允许区间 7 分 10 秒至 7 分 50 秒（大赛要求 5–8 分钟）。
- 画面：1920×1080，30fps，H.264，码率不低于 8 Mbps；片头片尾可用静帧加淡入淡出。
- 声音：旁白单独录制（AAC 192kbps、48kHz），背景音乐音量压到 -22dB 以下，操作提示音不使用。
- 字幕：简体中文硬字幕，微软雅黑或思源黑体 Bold，36px，位于底部安全区内，最多两行，每行不超过 18 字；专业术语首次出现时括号给出英文。
- 片头 5 秒：标题卡「CampusPulse AI｜让每一次校园决策都有可追溯的数据依据」＋团队名。
- 片尾 8 秒：技术栈一行、团队与指导教师、仓库与演示环境地址（不出现任何密钥）。
- 交付文件：CampusPulse-AI-演示视频-v1.0.mp4，随片提交本稿的 docx 与 pdf 版本。

## 四、逐段分镜与逐字旁白

### 镜 1｜0:00–0:35｜片头与问题定位

- 画面：0–5 秒为标题卡（深色底、青色高光），5 秒后淡入产品首页首屏，缓慢向下滚动两屏。
- 屏幕操作：1）打开产品首页；2）以每秒约半屏的速度滚动到「核心能力」区块；3）停在数据导入与分析的介绍卡片上。
- 旁白（逐字）：高校社团每个学期都在产生数据：报名表、签到表、预算表、问卷，还有一堆活动截图。它们分散在不同文件和聊天记录里，复盘靠手工整理，结论也很难说清楚来自哪一份材料。CampusPulse AI 想解决的就是这件事——把表格与图片证据放进同一个双语工作空间，让每一次分析都能追回到原始数据。
- 字幕标注：标题卡下方出现三行小字「数据分散 / 复盘耗时 / 结论难追溯」，逐行淡入。
- 易错点：首页不要出现任何登录态或个人信息；滚动速度要慢，保证 1080p 下文字可读。

### 镜 2｜0:35–1:20｜登录与多方式认证

- 画面：登录页，突出三种登录入口与 GitHub 按钮。
- 屏幕操作：1）点击右上角「登录」进入登录页；2）鼠标依次划过「密码登录」与「手机验证码」两个切换按钮；3）停在页面下方的「使用 GitHub 登录」按钮上高亮 2 秒；4）切回「密码登录」，输入评审演示账号的邮箱与密码（画面为掩码，字幕打码）；5）点击「登录」，出现身份验证弹窗时输入 6 位验证码（若演示账号未开启 2FA 则直接登录）；6）登录成功跳转总览页。
- 旁白（逐字）：登录支持三种方式：邮箱密码、手机验证码，以及管理员配置好 OAuth 应用后开启的 GitHub 授权登录。发送验证码和登录、注册、找回密码都会经过腾讯云人机验证；开启 2FA 的账号还要再输入认证器动态码。修改密码、换绑邮箱或手机号、开关 2FA 这类敏感操作，会先弹出身份验证窗口，只能使用账号已经绑定的方式，验证通过后才进入下一步。
- 字幕标注：三个入口分别加圆角高亮框，标注「密码」「手机验证码」「GitHub OAuth」；弹窗出现时标注「仅可使用已绑定的验证方式」。
- 易错点：密码框必须为掩码状态；演示邮箱使用虚构域名；人机验证若处于关闭状态，不要口播「已通过人机验证」，改为口播「可按站点策略开启」。

### 镜 3｜1:20–2:00｜总览与双语切换

- 画面：总览页（顶部为「2026年10月 · 社团运营空间」与问候语，下方四张指标卡）。
- 屏幕操作：1）鼠标划过「数据集」「分析记录」「报告」「平均数据质量」四张卡片；2）在顶部工作空间选择器中从个人空间切到社团空间，等待指标刷新；3）点击右上角「EN」，界面切换为英文，再点「中」切回；4）点击左侧导航「数据空间」。
- 旁白（逐字）：进入工作空间后，总览页先给出这个空间的运营概览：数据集数量、分析记录、报告数量和平均数据质量。这里有一个重要的设计——所有指标都来自当前空间和当前账号的真实数据，系统不会把写死的演示数字伪装成业务结果。界面支持中英文一键切换，团队里不同成员可以按自己的习惯使用。
- 字幕标注：指标卡上方标注「指标随空间切换实时重算」；语言按钮处标注「中文 / English 全站继承」。
- 易错点：切换空间后要等数字变化再切语言，避免画面同时发生两处变化。

### 镜 4｜2:00–3:05｜数据导入：表格与图片证据

- 画面：数据空间列表页 → 导入面板 → 数据集详情页。
- 屏幕操作：1）点击「导入数据」，把 data/demo/club-operations.csv 拖入上传区；2）等待提示「正在识别并保存：」变为「成功保存文件：」；3）点击新建的数据集进入详情，鼠标依次指向「记录数」「字段数」「质量评分」「已删除重复行」；4）下滑展示「字段字典与质量检查」与「缺失值总数」，再展示「数据预览（前 100 行）」表格；5）返回列表，再点「导入数据」，上传一张原创签到截图；6）进入该图片数据集详情，展示 OCR 原文区块与展开后的数据预览（例如 18 行、字段为序号/姓名/班级/日期）；7）点击「下载原文件」旁的返回，停留在预览表格上。
- 旁白（逐字）：先看表格导入。系统解析文件后自动识别字段，给出记录数、字段数、质量评分，并统计重复行和缺失值，字段字典会标出每一列是文本还是数值。图片也可以直接作为证据导入：视觉模型先做 OCR，识别出的表格会按行展开成结构化记录——列名取自表头，每一行是一条数据，所以行数、字段字典和后面的统计都基于展开后的真实行，而不是把整张图片压成一行。识别失败时，系统会明确提示没有可识别文字，或者说明 AI 服务不可用，不会编造内容。
- 字幕标注：CSV 详情处标注「字段字典 + 质量评分 + 去重」；图片详情处标注「OCR 表格按行展开：1 张图片 → 18 行记录」，并用箭头从 OCR 原文指向预览表格。
- 易错点：图片素材必须是原创或已脱敏；预览表格横向滚动时停 2 秒，让观众看清列名；不要用真实公假单原件。

### 镜 5｜3:05–4:25｜AI Agent 分析

- 画面：AI 分析页，左侧提问区，右侧「已保存的分析」。
- 屏幕操作：1）在顶部数据集选择器中选中刚导入的社团运营数据；2）在提问框输入「为什么 11 月签到下降？请给出证据和行动建议」；3）点击「开始分析」，按钮变为「正在执行工具调用…」；4）结果出现后，鼠标依次指向状态徽标（LIVE AI）、模型名与「置信度」；5）展开「实际执行的工具」列表，逐条停留；6）展开「异常」区块；7）展开「查看数据证据与工具输出」，滚动原始证据文本；8）在「行动建议」中点击一条建议的「加入任务」，出现「已保存为行动任务」提示；9）点击底部「创建图表」跳转到图表画布（衔接下一镜）。
- 旁白（逐字）：分析不是让模型直接写一段结论。Agent 会按需调用确定性工具：数据集画像、指标聚合、异常检测、图表推荐、知识检索和行动计划。报名数、签到数、转化率和异常候选都由代码计算，模型负责组织问题、选择工具和解释结果。所以每一条回答都带着工具调用链、证据引用和置信度，事实、推断和建议是分开展示的——数据已经证明的部分和需要人工复核的部分，一眼就能区分。分析结果可以一键存成行动任务，也可以直接进入图表画布或报告中心。
- 字幕标注：工具链每条前加序号；「置信度」处标注「模型自评，需人工复核」；证据区块标注「原始数据证据，可逐条回溯」。
- 易错点：若模型不可用，页面会显示降级或失败状态——此时应改用备用方案（见第八节），不要在视频中把降级结果说成模型输出。

### 镜 6｜4:25–5:25｜图表画布

- 画面：图表画布，左侧图表列表与 AI 推荐区，右侧画布主体。
- 屏幕操作：1）确认数据集选择器为社团运营数据，右上角提示「已保存到云端」；2）点击「AI 图表建议」，按钮变为「正在推荐…」；3）推荐卡片出现后，鼠标划过其中一张卡片的「分类 / 指标 / 汇总」信息；4）点击「全部加入画布」，图表出现在左侧列表并自动选中；5）在右侧展示柱状图或折线图渲染结果，底部显示「N 源数据行」与「分类字段 · 指标 · 汇总方式」；6）点击「导出 PNG」，展示下载文件（不打开文件内容）；7）在数据集选择器中切换到另一个数据集（例如图片数据集），左侧列表随之只显示该数据集的图表；8）切回原数据集，图表恢复。
- 旁白（逐字）：AI 推荐的图表可以一键导入画布，也可以手动新建：选择分类字段、数值字段和汇总方式即可。画布会自动保存到云端，刷新或换设备都能继续编辑，还能导出 PNG 直接用在小结里。这里有一个细节：图表是按数据集分别归属的，切换数据集时只显示当前数据集字段能支撑的图表，所以不会出现字段不存在导致的空图。
- 字幕标注：推荐卡片处标注「推荐前会校验字段是否真实存在」；切换数据集时标注「图表按数据源隔离」；导出后标注「PNG 2x 像素比」。
- 易错点：切换数据集后要等图表重绘完成再切回；不要在这一镜里删除图表，避免观众误解为数据丢失。

### 镜 7｜5:25–6:20｜报告中心

- 画面：报告中心，左侧生成区，右侧预览与下载区。
- 屏幕操作：1）在标题框输入「社团运营月报 · 2026年10月」；2）语言选择「中文」，点击「生成报告」，按钮变为「生成中…」；3）报告生成后，鼠标从上到下缓慢滚动预览，停在指标、异常、证据引用与行动建议段落各 2 秒；4）点击「编辑」，修改一句结论，点击「保存版本」；5）展开「历史版本」，点击「版本 1」回看旧版；6）依次点击「下载 Markdown」和「下载 DOCX」，展示浏览器下载记录（不打开文件）；7）点击「打印 / PDF」，在系统打印对话框中选择「另存为 PDF」并取消（只展示入口）；8）把语言切到「English」再生成一次，展示英文报告首屏。
- 旁白（逐字）：结论要变成可以交付的东西。报告中心会把指标、异常、证据引用和行动建议自动组织成一篇结构化报告，支持在线编辑和历史版本，随时可以回到上一版。导出提供 Markdown 和 DOCX，也可以通过浏览器打印为 PDF，方便提交给指导老师或在例会上分享。同一份数据可以分别生成中文和英文报告，供不同背景的成员阅读。
- 字幕标注：版本区标注「每次保存生成新版本，可回溯」；下载按钮处标注「Markdown / DOCX / 打印 PDF」；英文报告处标注「双语报告，同一数据来源」。
- 易错点：不要在报告中出现真实姓名或学号；打印对话框只展示不确认，避免生成无关文件。

### 镜 8｜6:20–7:05｜权限、审计与系统配置

## 五、完整旁白逐字稿（配音用）

【0:00】高校社团每个学期都在产生数据：报名表、签到表、预算表、问卷，还有一堆活动截图。它们分散在不同文件和聊天记录里，复盘靠手工整理，结论也很难说清楚来自哪一份材料。CampusPulse AI 想解决的就是这件事——把表格与图片证据放进同一个双语工作空间，让每一次分析都能追回到原始数据。

【0:35】登录支持三种方式：邮箱密码、手机验证码，以及管理员配置好 OAuth 应用后开启的 GitHub 授权登录。发送验证码和登录、注册、找回密码都会经过腾讯云人机验证；开启 2FA 的账号还要再输入认证器动态码。修改密码、换绑邮箱或手机号、开关 2FA 这类敏感操作，会先弹出身份验证窗口，只能使用账号已经绑定的方式，验证通过后才进入下一步。

【1:20】进入工作空间后，总览页先给出这个空间的运营概览：数据集数量、分析记录、报告数量和平均数据质量。这里有一个重要的设计——所有指标都来自当前空间和当前账号的真实数据，系统不会把写死的演示数字伪装成业务结果。界面支持中英文一键切换，团队里不同成员可以按自己的习惯使用。

【2:00】先看表格导入。系统解析文件后自动识别字段，给出记录数、字段数、质量评分，并统计重复行和缺失值，字段字典会标出每一列是文本还是数值。图片也可以直接作为证据导入：视觉模型先做 OCR，识别出的表格会按行展开成结构化记录——列名取自表头，每一行是一条数据，所以行数、字段字典和后面的统计都基于展开后的真实行，而不是把整张图片压成一行。识别失败时，系统会明确提示没有可识别文字，或者说明 AI 服务不可用，不会编造内容。

【3:05】分析不是让模型直接写一段结论。Agent 会按需调用确定性工具：数据集画像、指标聚合、异常检测、图表推荐、知识检索和行动计划。报名数、签到数、转化率和异常候选都由代码计算，模型负责组织问题、选择工具和解释结果。所以每一条回答都带着工具调用链、证据引用和置信度，事实、推断和建议是分开展示的——数据已经证明的部分和需要人工复核的部分，一眼就能区分。分析结果可以一键存成行动任务，也可以直接进入图表画布或报告中心。

【4:25】AI 推荐的图表可以一键导入画布，也可以手动新建：选择分类字段、数值字段和汇总方式即可。画布会自动保存到云端，刷新或换设备都能继续编辑，还能导出 PNG 直接用在小结里。这里有一个细节：图表是按数据集分别归属的，切换数据集时只显示当前数据集字段能支撑的图表，所以不会出现字段不存在导致的空图。

【5:25】结论要变成可以交付的东西。报告中心会把指标、异常、证据引用和行动建议自动组织成一篇结构化报告，支持在线编辑和历史版本，随时可以回到上一版。导出提供 Markdown 和 DOCX，也可以通过浏览器打印为 PDF，方便提交给指导老师或在例会上分享。同一份数据可以分别生成中文和英文报告，供不同背景的成员阅读。

【6:20】权限方面，个人空间与社团空间严格隔离，成员按角色授权，数据集、原文件、分析、图表和报告都跟随空间权限。管理员空间可以配置全站：登录方式、邮件与短信服务、人机验证、AI 服务、导入限制，以及 GitHub 授权登录的开关与凭据；所有密钥都加密保存在服务器，界面只显示是否已配置，绝不回显明文。账号侧，用户可以在设置页绑定认证器、更新恢复码、修改密码，也可以关联或解绑 GitHub；每一次配置变更和敏感操作都会写入审计日志，保留操作人、时间和结果。

## 七、降级与备用方案

- AI 服务不可用（例如上游余额不足或超时）时，分析与报告无法生成：改用仓库内置的确定性演示数据路径录制镜 5，并在字幕中明确标注「本地演示路径，非实时模型输出」，不得把降级结果表述为模型实时结论。
- 图片 OCR 不可用时，镜 4 只录制表格导入部分，图片段落改为静态截图讲解，并说明系统会返回明确的失败原因。
- 人机验证处于关闭状态时，镜 2 的旁白改为「站点可按策略开启腾讯云无感与图形验证」，不要展示未发生的验证过程。
