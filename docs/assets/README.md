# Project images

These locally captured screenshots illustrate the currently deployed CampusPulse AI public interface and are used in the project introduction.

- `production-homepage-hero.png`: cropped homepage preview area.
- `production-homepage.png`: full homepage capture.
- `production-login.png`: public login screen.

Any dashboard figures visible in the homepage preview are illustrative interface content, not measured campus outcomes. The dataset-detail image uses a small synthetic fixture generated for responsive browser tests. The public captures exclude private account information.
