# 安全与隐私

## 身份与权限

- 服务端对私有业务请求校验登录状态、账号状态、空间角色和资源归属。
- 全站系统管理员与空间管理角色分离；空间成员不能读取平台级服务凭据。
- 账号敏感操作通过已绑定验证方式和一次性许可保护；TOTP 与恢复码应防止重放。

## 凭据与账号

- 生产凭据由服务器环境或加密配置保存，不提交至仓库、PDF、截图和录屏。
- 配置页面不回显 SMTP、短信、模型、人机验证、OAuth 或存储密钥。
- 验证码、恢复码和密码不得出现在审计日志或错误信息中。
- 评审账号为高权限账号，应经受控渠道提供，并在评审结束后停用或轮换。
- 公开仓库中不得记录可登录生产系统的密码，即使该密码被称为演示凭据。

## 数据与文件

- 对象存储保持私有，通过已授权的应用请求读取。
- 文件类型、大小和记录限制由服务端验证；上传数据不得作为可执行脚本或可信指令。
- 演示优先使用原创合成数据。使用真实学生数据前应获得合法授权并遵守最小化原则。
- AI/OCR 结果是辅助信息，重要统计与结论需要对照原始记录核验。

## 网络与运行

- 生产使用 HTTPS；反向代理不得缓存登录、验证码、用户设置和私有业务响应。
- 数据库与对象存储控制接口仅允许必要的可信服务访问。
- 依赖补丁、账号、日志、证书与可恢复备份需要持续维护。
- Demo 登录仅用于隔离的本地测试环境，生产必须关闭；只有显式设置 `DEMO_EMAIL` 和 `DEMO_PASSWORD` 才会接受 demo 凭据，源码不提供默认账号密码。

## 验证边界

项目自动化测试不是独立渗透测试、安全认证或第三方合规证明。发布前仍需检查目标环境、外部供应商状态和当期依赖公告。
