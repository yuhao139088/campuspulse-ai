# 生产安全与验证

- 业务API校验真实用户、账号启用状态、认证版本和空间角色；系统管理员明确拥有全站管理权限，空间管理员没有全站服务权限。
- 数据集、原文件、分析、画布与报告按空间授权；S3、数据库与应用端口仅监听本机。
- Nginx显式关闭本站代理缓存，避免旧登录页和不同用户共享认证响应。匿名API在已认证访问之后仍验证401。
- 密码bcrypt散列；验证码10分钟/单次/最多5次错误/60秒重发，PostgreSQL事务锁防并发发送，重发使旧码失效。
- SMTP、AI、短信和腾讯凭据加密存库、不回显，部署密钥与验证码不写公开审计。
- 腾讯普通/无感应用分开，真实后端票据校验；无感要求EvilLevel=0，拒绝容灾/恶意/复用票据。随机登录许可绑定IP、账号、认证版本与操作，直接绕过前端调用登录回调仍被拒绝。
- 2FA在主凭据通过后弹独立窗口；未验证第二因子不建立会话。TOTP防时间步重放，恢复码仅用一次；更改认证方式或密码撤销旧会话。
- 文件限20MB/20000行/150列，可由系统管理员降低；不执行上传文件，模型将内容视为不可信证据。
- 专用服务账号、systemd写入限制/内存限制、TLS证书自动续期、数据库及对象一致备份。

自动验证包含密码/验证码/TOTP/恢复码、普通用户隔离、系统管理员配置权限、腾讯风险结果处理、受保护API匿名访问、真实浏览器登录与2FA工作流。开发演示模式仅用于隔离的本地测试，生产关闭。

短信服务需配置真实供应商；缺失时不显示伪发送成功。GitHub授权登录按照后续集成任务单独启用。
